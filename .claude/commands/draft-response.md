Read CLAUDE.md first. Draft a response from a reviewed, approved, unembargoed statement.

Run `npm run media -- draft-response <inquiry> --actor=`. Replace placeholders with the operator's actual values, quote arguments containing spaces, and omit unused optional flags. All commands accept `--json`. Run help if an argument is unclear. Never copy the square-bracket notation into a shell.

Read the relevant contact, enquiry or release before changing it. Use the recorded operator as actor. An actor label is not authentication.

Present the saved internal draft and its source revision in chat. Never send or publish it. An approval or embargo error is a required review, not permission to bypass the check.
