Read CLAUDE.md first. Record a different reviewer approving the current revision.

Run `npm run media -- approve-release <release> --revision=N --evidence= --actor=`. Replace placeholders with the operator's actual values, quote arguments containing spaces, and omit unused optional flags. All commands accept `--json`. Run help if an argument is unclear. Never copy the square-bracket notation into a shell.

Read the relevant contact, enquiry or release before changing it. Use the recorded operator as actor. An actor label is not authentication.

Approval requires a different reviewer, the current revision number and evidence of their decision. Never approve on your own or infer permission from an earlier revision.
